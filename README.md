# Pip's Glide

An open-sky glider game about Pip, a little fox spirit, launching from a sky island on a leaf
glider. Ride thermals, skim island tops, light twelve beacons across four skies to the Star Nest,
fly a new Daily Wind every day, and spend the feathers you collect on glider upgrades.

**▶ Play in your browser: https://nerojust.github.io/pips-glide-web/**

Works offline once loaded, and can be installed as an app from the browser menu. Keyboard,
mouse, touch and game controllers all work.
